# Experimental runtime source snapshot

[中文](README.md) · [Home](../README.en.md)

The three component directories contain all Python modules shipped in the experimental JiuwenSwarm, openJiuwen agent-core and Replay wheels, along with shipped text sources and licenses. The wheel distributions reflect the published build and do not imply that upstream development-only files were included. For binary assets, compiled frontend assets and exact installation, use the [complete original ZIP](https://github.com/qwqwqwqwqwqwqwqwqe/jiuwenswarm-rewind-bench/releases/tag/runtime-20261112-173855).

See the [extraction summary](snapshot-summary.json) for counts and the [build manifest](package/manifest.json) for upstream revisions and hashes. Licenses and notices are under each component's `*.dist-info/licenses/`. The installer is run from the complete unpacked release with its sibling `wheels/` directory. The project runtime overlay is documented in the [integration guide](../docs/jiuwenswarm.en.md).
